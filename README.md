# MediaShelf

Личная медиатека игр, фильмов, сериалов и аниме. Каталог, рейтинги, магазины и собственные прохождения в одном интерфейсе.

## Запуск

Node.js 24. Команды выполняются в `D:\Projects\MediaShelf`:

```powershell
npm install
npm run dev
```

Открыть http://127.0.0.1:5173. Production:

```powershell
npm run build
npm run start
```

Production работает на http://127.0.0.1:4173. Адрес и порт задаются через `HOST` и `PORT`.

## Возможности

### Страницы

- `/` — главная «Чарты»: популярное, хиты всех времён и подборки.
- `/search` — поиск, категории и подробные фильтры.
- `/library` — «Моя полка», прогресс и доска статусов.
- `/today` — «Что сегодня?», случайный выбор из каталога или коллекции.
- `/profile` — профиль этого браузера: статистика, настройки и резервные копии.

Переходы работают через React Router; прямые ссылки, обновление страницы и кнопки браузера «Назад/Вперёд» поддерживаются. Поисковый запрос, категория и фильтры сохраняются в URL. Общая коллекция доступна на всех страницах.

Дизайн дорабатывается поэтапно вместе с пользователем, начиная с главной: `src/pages/ChartsPage.tsx` и ограниченные `.charts-page` стили в `src/pages/charts.css`.

### Каталог и коллекция

- Почти чёрный интерфейс с приглушённым золотом: скрывающийся header и фиксированная поисковая навигация.
- Единые меню категорий, сортировки и сезонов работают нажатием и с клавиатуры. Поиск предлагает произведения, недавние просмотры и жанры.
- На главной — нумерованная постерная подборка и открытое переключение пяти категорий. Режимы «Популярно сейчас» и «Хиты всех времён» сохраняются в адресе страницы.
- Номер карточки — позиция в подборке MediaShelf, а не мировой рейтинг. Оценки IMDb/Steam подписаны отдельно; кнопки сохранения и избранного расположены под постером. На телефоне — две колонки.
- Постеры 2:3 сохраняют пропорции. Неработающие обложки уходят после остальных. Настоящее видео или кадры доступны в управляемом preview без изменения размера карточки.
- Жанры, годы, статусы, оценки, платформы, магазины, языки, цена и скидки. Фильтры действуют на загруженные результаты.
- Выбор нескольких личных платформ и магазинов; настраиваемый регион цен.
- Steam показывается первым, когда его предложение подтверждено. Остальные магазины доступны отдельными ссылками с иконками.
- Для игры можно завести до десяти независимых прохождений, например Xbox и PC / Epic Games. У каждого свой процент и набор отметок.
- «Пройдено» совместимо с 80% и с отметкой «Играю». Изменение отметок не меняет проценты. Удаление прохождения подтверждается и не затрагивает остальные; игра без отметок остаётся на доске.
- У фильмов только «В планах» и «Просмотрено». У сериалов и аниме — реальные сезоны и эпизоды с независимыми отметками и отзывами, ручным дополнением и сохранённым offline-списком.
- Личная оценка 1–10, избранное, заметки, доска статусов и статистика без двойного подсчёта произведений.
- Рулетка: библиотека или каталог, чекбоксы четырёх категорий, анимация с остановкой и открытие результата.
- Мобильная версия, клавиатура и уменьшение анимаций. WebGL и библиотеки 3D удалены.

Клавиши `/` и `Ctrl+K` открывают поиск; стрелки выбирают подсказку, `Enter` открывает результат, `Escape` закрывает панель или диалог.

## Каталоги, цены и рейтинги

- **Steam:** каталог, метаданные, языки, цена и процент положительных пользовательских отзывов. Поиск дополнительно исключает DLC, подтверждённые appdetails; при недоступности проверки неизвестная запись сохраняется.
- **GOG:** независимый игровой каталог, изображения и цены. Полные издания объединяются с соответствующей игрой; редакторы, саундтреки и демонстрации исключаются из нормализованной выдачи.
- **IMDb:** поиск фильмов и официальный ежедневный набор `title.ratings.tsv.gz` с оценкой и числом голосов.
- **Cinemeta:** популярные фильмы и сериалы, жанры, фоновые изображения и дополнительные сведения, сопоставленные по IMDb ID.
- **TVmaze:** сериалы и подтверждённые списки сезонов. **Shikimori:** аниме и жанры.
- **Epic и консоли:** подтверждённые страницы отдельных игр в `server/store-links.ts`; Genshin Impact доступен отдельной записью. Это не полный поисковый API этих магазинов.

Цены автоматически приходят из Steam и GOG. Для остальных площадок показывается «Смотреть в магазине», пока цена не подтверждена источником. Разные валюты не пересчитываются и не сравниваются как одинаковые суммы. Регион доступен в «Мои платформы».

Рейтинг IMDb, доля положительных отзывов Steam и личная оценка — отдельные величины. Режим популярности использует порядок источников, разнообразие категорий и франшиз; единого мирового рейтинга сервис не заявляет. «Хиты всех времён» использует редакционные отправные точки и данные источников.

Рейтинги IMDb хранятся в `.cache/imdb-ratings.sqlite`. Первый запрос запускает фоновое обновление, затем снимок обновляется не чаще раза в сутки. Новый снимок заменяет предыдущий только после успешной загрузки. Прогреть заранее:

```powershell
node scripts/sync-ratings.ts
```

Файл `.cache/` не содержит личную коллекцию, исключён из Git и может быть восстановлен из источника. IMDb предоставляет этот набор для личного и некоммерческого использования: https://developer.imdb.com/non-commercial-datasets/.

Число сезонов аниме показывается только при подтверждённом сопоставлении, без подсчёта фильмов и спецвыпусков как сезонов. Если данных нет, диалог сообщает об этом. Некоторые встроенные аниме представляют конкретный сезон; их исходный счётчик эпизодов сохраняется.

## Личные данные и резервные копии

Коллекция и настройки сохраняются в `localStorage`, ключ `mediashelf-library`. Недавние просмотры используют `mediashelf-recent`, настройка анимаций — `mediashelf-calm-mode`.

Новая резервная копия имеет версию **3**. Копии версий **1/2/3** и существующие коллекции читаются с переносом старого игрового прогресса в основное прохождение. Магазин не назначается по источнику метаданных: наличие карточки в Steam не означает владение Steam-копией.

Старый счётчик эпизодов сохраняется как непривязанный прогресс; распределение по конкретным сериям выполняется только явной кнопкой. Обновления каталога сохраняют ручные эпизоды и отзывы. Выбранный сезон запоминается в sessionStorage на время вкладки. Завершение списка вышедших серий не означает автоматическое завершение продолжающегося сериала.

Импорт заменяет коллекцию после подтверждения. Некорректный импорт не изменяет её. При повреждении сохранённой записи исходное содержимое не перезаписывается. Максимум резервной копии — 16 МБ; добавленных внешних и собственных произведений — 500.

Регистрации и облачной синхронизации нет. Оценки, заметки и прогресс не отправляются каталогам. Открытие сохранённой полки не требует доступности внешних сервисов.

## API

- `GET /api/catalog?type=all&q=...&page=1&country=US&order=popular`
- `POST /api/details?country=US` — массив до 12 карточек с валидируемыми идентификаторами; обновляет их метаданные, не личные записи.
- `GET /api/details?ids=...&country=US` — подробности известных серверу карточек.
- `GET /api/health`
- `POST /api/episodes` — массив с одним сериалом/аниме; реальный список TVmaze либо Cinemeta. Личные отметки в запрос не включаются.

Один серверный слой используется Vite и production-сервером. Запросы кешируются, одинаковые обращения объединяются, параллелизм ограничен. Для Shikimori дополнительно выдерживается интервал. Частичный сбой не блокирует остальные источники.

## Проверки

```powershell
npm run lint
npm run typecheck
npm test
npm run build
$env:TEST_SERVER = '1'
npm run test:e2e
npm run format:check
```

Playwright использует отдельный сервер на 4173 и чистые браузерные профили. В Windows нужен Microsoft Edge. Браузерные сценарии изолированы от внешних цен и наличия сети через тестовые ответы API. Живая проверка при работающем dev-сервере:

```powershell
npm run capture:ui
```

Скриншоты ПК, телефона, поиска, рулетки и предложения «Ведьмака» сохраняются в `.impeccable/review`. Отдельно проверяется реальная анимация рулетки. Воспроизводимая матрица 1440/1024/768/390 с изолированной коллекцией: `node scripts/design-review.mjs pass-3`; необязательные числовые аргументы ограничивают ширины. Итоги и ограничения — `DESIGN-REVIEW.md`.

## Структура и оформление

- `src/App.tsx` — маршруты, общая оболочка, диалоги и действия коллекции.
- `src/pages/` — отдельные страницы чартов, поиска, полки, случайного выбора и профиля.
- `src/components/SiteHeader.tsx`, `src/lib/navigation.ts` — общая навигация.
- `src/components/CatalogBrowser.tsx`, `SearchNavigation.tsx` — каталог, поиск и фильтры.
- `src/components/StorefrontDialogs.tsx` — диалог настроек и панель случайного выбора.
- `src/components/PlaythroughEditor.tsx` — независимые прохождения.
- `src/components/EpisodePanel.tsx`, `src/lib/episodes.ts`, `server/episodes.ts` — реальные эпизоды, отзывы, сохранение и миграция.
- `src/components/PreviewPoster.tsx`, `MediaPreview.tsx` — hover/touch preview и управление медиа.
- `src/lib/library.ts` — проверка данных и перенос резервных копий.
- `src/lib/discovery.ts` — объединение и разнообразие выдачи.
- `server/catalog.ts`, `metadata.ts`, `ratings.ts` — каталоги, подробности и официальный снимок рейтингов.
- `public/covers` и `public/backdrops` — локальные изображения; происхождение фоновых изображений указано в `sources.json`.

React 19, TypeScript, Vite 8, Motion, Zustand, Zod, Radix UI, dnd-kit, Tailwind CSS, Lucide и Simple Icons. Дизайн описан в `DESIGN.md`, продукт — в `PRODUCT.md`. Иконки брендов используются для обозначения соответствующих источников. Изображения принадлежат их правообладателям.
