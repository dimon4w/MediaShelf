# MediaShelf / личная программа кинопоказов

Режим: operate. Пользователь самостоятельно выбирает произведения и сохраняет личные впечатления. Полный редизайн разрешён, данные и действующие возможности обязательны к сохранению. Дизайнерские решения явно делегированы, поэтому отдельное подтверждение направления не требуется.

## Direction contract

THESIS: Произведение и личная история важнее служебной статистики. Постерная библиотека соединяет выбор на вечер, независимые прохождения и посезонные заметки без панели показателей.

OWN-WORLD: Почти чёрные поверхности, белый текст, светло-серые пояснения, один приглушённый золотистый акцент. Manrope для задач, Unbounded только для короткого названия выбранной истории. Прямые края постеров, мелкие функциональные радиусы, отсутствие декоративного стекла.

STORY: Выбрать категорию, рассмотреть постер, при желании открыть настоящий preview, сохранить произведение и продолжить с нужного сезона или платформы.

FIRST VIEWPORT: Двухуровневое управление сверху, компактная редакционная витрина высотой около 300px с настоящим постером, пять крупных переключателей, начало постерного каталога. Верхняя полоса скрывается вниз; поиск остаётся доступен. На телефоне композиция перестраивается, сохраняя крупные действия.

FORM: Назначенное направление 5; seed 9117e869. Семь исходных систем: киноархив, домашняя медиатека, монтажный лист, библиотечная картотека, личная программа кинопоказов, выставочный каталог, музыкальная коллекция. Шесть внешних кандидатов отклонены: nixie — числа вместо контента; datamatics — слишком абстрактно; star atlas — пространственная карта мешает выбору; Game Boy — противоречит типографике; orizuru — ритуал складок не соответствует задаче; tensegrity — ненужная пространственная механика. Взята дисциплина фиксированных числовых полей, линейных списков, явного выбора и обратимых состояний, без декоративного заимствования.

SIGNATURE: Постер превращается в управляемый preview без изменения рамки. Случайная рекомендация — короткий проход постеров с ясно обозначенным результатом. Непрерывные декоративные анимации исключены.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
